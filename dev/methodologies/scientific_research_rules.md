## 0. المبدأ الأساسي

> "لازم برهان كامل — تفسير كامل مش أي حاجة منبه علي فراغ.
>  الأقوى أهم — يكون مجرب وعملي وله اختبارات حقيقية من A لـ Z.
>  ليس نظري. لازم منشور بالكامل ومفتوح ولينا وصول كامل بتفاصيله.
>  كل ما تكون تفاصيل أكثر وقوي = أولوية أعلى."

## 1. شروط القبول الإلزامية (Acceptance Criteria)

كل ورقة بحثية يجب أن تجتاز **كل** الشروط التالية. فشل في شرط واحد = رفض فوري.

### 1.1 الشروط الخمسة الذهبية

| # | الشرط | التفصيل | كيفية التحقق |
|---|-------|---------|-------------|
| G1 | **مفتوحة الوصول (Open Access)** | النص الكامل متاح بدون دفع أو تسجيل | arxiv.org، proceedings.open، GitHub README |
| G2 | **مجربة عملياً (Empirically Validated)** | نتائج تجريبية حقيقية — ليس فقط نظرية | جداول نتائج + أرقام + benchmarks |
| G3 | **اختبارات من A لـ Z (End-to-End Tested)** | التقييم يشمل النظام الكامل من المدخل للمخرج | خط أنابيب كامل (pipeline) مُقيَّم |
| G4 | **كود مفتوح المصدر (Open Source Code)** | السورس كود متاح ويمكن تشغيله | GitHub repo نشط + README + installable |
| G5 | **منشورة بالكامل (Fully Published)** | ليست preprint بدون peer review (إلا إذا كانت مرجعية استثنائية) | arXiv ID + venue أو GitHub stars > 100 |

### 1.2 شروط الجودة الإضافية

| # | الشرط | الأولوية |
|---|-------|----------|
| Q1 | كلما زادت التفاصيل = أولوية أعلى | 🔴 |
| Q2 | منحنيات تطور النتائج (learning curves) | 🟡 |
| Q3 | مقارنة مع baselines متعددة | 🟡 |
| Q4 | تحليل الأبعاد والمحاور (ablation studies) | 🟡 |
| Q5 | السورس كود مُوثق وقابل للصيانة | 🔴 |
| Q6 | تاريخ النشر: 2024-2026 مفضل (حديث) | 🟡 |
| Q7 | الاستشهادات: ورقة مُستشهد بها كثيراً = أفضل | 🟡 |

## 2. معايير الترتيب (Ranking Criteria)

كل ورقة تُقيَّم بدرجة من 0-100:

```
SCORE = (G1×20) + (G2×20) + (G3×20) + (G4×20) + (G5×10) + (Q_BONUS×10)

WHERE:
  G1-G5: 0 أو 1 (اجتاز أو فشل)
  Q_BONUS: 0-10 (تفاصيل + عمق + منحنيات + أبعاد)
```

### تفسير الدرجات:

| الدرجة | التصنيف | الإجراء |
|--------|---------|---------|
| 90-100 | 🟢 ممتازة — أولوية قصوى | استخدم فوراً + استخرج كل شيء |
| 70-89 | 🟡 جيدة — أولوية عالية | استخدم بعد المراجعة |
| 50-69 | 🟠 مقبولة — أولوية متوسطة | استخدم للسياق فقط |
| <50 | 🔴 مرفوضة | لا تستخدم |

## 3. قالب تقرير الورقة (Paper Report Template)

كل ورقة تُوثَّق بالشكل التالي في `dev/papers/`:

```markdown
# [عنوان الورقة]

## البيانات الأساسية
- **arXiv ID:** (إذا وجد)
- **التاريخ:** YYYY-MM
- **المؤلفون:** (المؤسسات)
- **Venue:** (مؤتمر/مجلة)
- **GitHub:** (رابط الكود)
- **درجة التقييم:** XX/100
- **التصنيف:** 🟢/🟡/🟠/🔴

## ملخص (Abstract — بالعربي)
[3-5 أسطر]

## المشكلة اللي بحلها
[ما المشكلة التي تحاول الورقة حلها]

## الحل المقترح
[المنهجية والبنية]

## النتائج الرئيسية
[أرقام + جداول + benchmarks]

## ما أخذناه (What We Stole)
[ما الذي نستخدمه في AI Earth]

## ما لم نأخذه (What We Missed)
[ما تركناه ولماذا]

## كيف اختلف تطبيقنا (GENESIS/AI Earth Adaptation)
[التكييف مع مشروعنا]

## التكامل مع AI Earth
[في أي Layer وComponent يتم الدمج]

## ملاحظات
[أي تحفظات أو مخاطر]

## روابط
- [الورقة](url)
- [الكود](url)
- [العرض](url — إن وجد)
```

## 4. بروتوكول البحث (Search Protocol)

### الخطوة 1: تحديد النطاق
```
INPUT: F. يقول "ابحث عن ورقة في [الموضوع]"
OUTPUT: قائمة مرشحة بأول 10 نتائج
```

### الخطوة 2: التصفية الأولية
```
FOR each ورقة:
  IF NOT Open Access → REJECT
  IF NOT Empirical → REJECT (نظري فقط)
  IF NO Code Available → FLAG (قد يُقبل إذا كان استثنائياً)
```

### الخطوة 3: التقييم العميق
```
FOR each ورقة نجحت في التصفية:
  احسب SCORE (حسب المعادلة أعلاه)
  اكتب تقرير بالقالب
  صنّف حسب الدرجة
```

### الخطوة 4: العرض
```
FOR F.:
  اعرض أعلى 3 أوراق بالترتيب
  لكل واحدة: درجة + ملخص + لماذا مفيدة + ماذا نسرق
  انتظر الموافقة
```

### الخطوة 5: التوثيق
```
AFTER الموافقة:
  احفظ التقرير الكامل في dev/papers/
  أضف للـ Knowledge Graph في dev/memory/
  أضف في COMPONENT_CATALOG (أين يُدمج)
```

## 6. قائمة المحرمات (Things to NEVER Do)

```
❌ لا تستخدم ورقة مغلقة (paywalled) بدون بديل مفتوح
❌ لا تقبل ورقة نظري فقط بدون تطبيق عملي
❌ لا تتجاهل missing tests — إذا الورقة بتدعي نتائج بدون كود = اشتبه
❌ لا تأخذ رقم من الورقة بدون التحقق من السياق (context)
❌ لا تخلط بين "نتائج على dataset محدد" و"نتائج عامة"
❌ لا تنسخ كود بدون فهم — لازم تفهم كل سطر تضيفه
❌ لا تضيف ورقة بدون ملخص بالعربي
❌ لا تضيف ورقة بدون تحديد "ما أخذناه وما تركناه"
```
